# 全国4紙 社説統合 RSSフィード

朝日新聞、読売新聞、毎日新聞、日本経済新聞の社説を自動巡回し、統合したRSS 2.0フィードを毎日更新配信するシステムです。

## 配信RSSフィード
- **RSS URL**: `https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/feed.xml`

## 仕様
- **更新時刻**: 毎朝 7:00 JST
- **接頭辞**:
  - `[朝日]` 朝日新聞社説
  - `[読売]` 読売新聞社説
  - `[毎日]` 毎日新聞社説
  - `[日経]` 日本経済新聞社説
- **保持件数**: 直近最大 200 件
